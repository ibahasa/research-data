# Moved

This dataset now lives in a separate repository:

**https://github.com/ibahasa/benchmark-nusantara/tree/main/raw/benchmark-runs-archived**

## Why

Benchmark data and the rest of our research data change at completely different
speeds. An article pins its provenance link to a commit SHA so the reader sees
the data exactly as it stood when the sentence was written, and a Zenodo release
must not move. Benchmark data is the opposite: it changes every time a model is
run. Keeping both in one repository meant every benchmark run dirtied the
repository that articles cite.

The two were separated on 2026-08-16.

## Links published before that date still work

Every article link into this repository is pinned to a commit SHA, and a commit
permalink serves the tree as it stood at that commit rather than whatever `main`
holds today. Removing the files here does not break a single one of them.

If you followed such a link and want the current version of this data, the
repository above is where it is maintained.
